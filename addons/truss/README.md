# Truss

Structured architecture for GDScript (Godot 4.5+). Every piece is optional: typed events, game phases and state
machines, content databases, stats, wallets and per-level prices, save files, pause tokens, and for bigger games
dependency injection, feature modules, commands and queries, and a layer linter.

After installing, enable **Truss** in Project Settings → Plugins. It adds the `Truss` autoload and a **Truss**
tab to the Debugger panel.
