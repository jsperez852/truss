# RFC 0002 — Truss 0.5: content and gameplay primitives

| | |
|---|---|
| Status | **Implemented** in Truss 0.5.0 (Q1–Q5 as proposed) |
| Date | 2026-11-08 |
| Target | Truss 0.5.0 (Godot 4.5+, same as 0.4) |
| Evidence | Review of seven real projects by the same author (one 9,900-line action roguelite, an idle game, a platformer, two arcade games); findings below cite them generically |

## 1. Summary

Truss 0.1–0.4 covers architecture: contracts, DI, modules, messaging, state machines and tooling. A review of real
projects shows the next gap is **gameplay primitives** that every mid-sized game hand-writes, usually several times,
and that interact badly with the engine when written naively. 0.5 adds five of them, extends two existing pieces,
and adds a light adoption guide:

| # | Piece | Kind |
|---|---|---|
| A | `TrRegistry`: content database of Resources | new |
| B | `TrStat` / `TrModifier` / `TrStats`: values with stacked modifiers | new |
| C | `TrPause` tokens, hit stop and app lifecycle events | new |
| D | `TrEventBus`: priority and source filtering | extension |
| E | `TrStateMachine`: transition arguments and intents | extension |
| F | Readable names for inner classes (`Outer.Inner`) | fix |
| G | "Truss Lite" guide and an `arch_check` rule for stateful Resources | docs, tooling |

Out of scope for 0.5 (section 10): an idle-economy module, save system, dialogue, object pools.

## 2. Evidence

|---|---|---|

| Hand-written weighted random pick over loaded content | 1 | A |
| `duplicate_instance()` written by hand because a Resource holding runtime state is shared between users | 5 classes, plus 2 `duplicate()` calls | A, G |

| `get_tree().paused` toggled directly; only one of five callers restores the previous state, so a hit stop ending while a menu is open unpauses the game | 5 scripts | C |

## 3. Verified engine facts (Godot 4.5.1 and 4.7.2)

- `ResourceLoader.list_directory(path)` exists on both and returns `["a.tres", "b.tres", "sub/"]`: subfolders end
  with `/`, and exported builds list original names, not `.remap` files.
- `Resource.duplicate_deep()` exists on both.
- `NOTIFICATION_APPLICATION_FOCUS_OUT` (2017), `NOTIFICATION_APPLICATION_PAUSED` (2015) and
  `NOTIFICATION_WM_CLOSE_REQUEST` (1006) exist on both.
- An inner class of a **named** script can be found through `ProjectSettings.get_global_class_list()` and
  `get_script_constant_map()`: `OuterNamed.Deep` resolves on both. Inner classes of unnamed scripts can't.
- A timer that ignores the time scale is accurate within one frame (0.2 s requested, 194–200 ms measured with
  `Engine.time_scale = 0.05`). An earlier 126–134 ms reading came from measuring during startup. With `--fixed-fps`,
  timers follow simulated time. Q4 resolved: hit stop uses `time_scale`.

## 4. A — TrRegistry

```gdscript
var attacks := TrRegistry.new(BaseAttack)
var scan: TrResult = attacks.scan("res://data/attacks", true)     # recursive; failure lists bad files
attacks.all()                                   # Array of BaseAttack (shared, read-only definitions)
attacks.by_id(&"slash")                         # key: an `id` property if present, else the file's basename
attacks.where(func(a: BaseAttack) -> bool: return a.is_basic_attack)
attacks.pick_weighted(rng, func(a: BaseAttack) -> float: return a.weight)
attacks.instantiate(&"slash")                   # duplicate_deep(): a private copy for runtime state
```

- Uses `ResourceLoader.list_directory()`, so it works in exported builds. A test exports a project and checks it.
- Only resources that are instances of the given script (or subclasses) are kept. Others are reported in the
  scan result, never silently skipped.
- Duplicate ids are a scan failure. The registry is a plain `RefCounted`, registered as a singleton per content type.
- `pick_weighted` takes the RNG as an argument so tests are deterministic.

## 5. B — TrStat, TrModifier, TrStats

```gdscript
var damage := TrStat.new(10.0)
damage.add(TrModifier.flat(5.0, sword))          # +5
damage.add(TrModifier.percent(0.2, buff))        # +20 % (percentages add together)
damage.add(TrModifier.multiply(1.5, rage))       # ×1.5 (multipliers multiply)
damage.value                                     # (10 + 5) × (1 + 0.2) × 1.5 = 27.0
damage.remove_from(buff)                         # removes every modifier from that source
damage.changed.connect(_on_damage_changed)       # (old, new), only when the value changes
```

- Formula: `(base + Σ flat) × (1 + Σ percent) × Π multiply`, then optional `min_value` / `max_value` clamps.
  (Implementation note: the planned per-modifier `order` was dropped. Within a kind the operations commute, so
  it had no effect.)
- The value is cached and recomputed only when something changes.
- `TrStats`: a set of named stats with **declared** keys: `TrStats.new({&"speed": 220.0, &"damage": 10.0})`.
  Reading or modifying an undeclared key is an error, which prevents the missing-key bug seen in the review.
- `TrModifierDef` (`Resource`) so modifiers can be authored in the inspector, for items and improvements:
  `@export var stat: StringName`, `kind`, `value`. `def.apply_to(stats, source)` / `stats.remove_from(source)`.
- Sources are any `Object` or `StringName`; modifiers from a freed source are dropped on the next recompute.

## 6. C — Pause tokens, hit stop, app lifecycle

```gdscript
var token: TrPauseToken = Truss.pause.acquire(&"inventory_menu")   # game pauses while any token is held
token.release()                                                     # or let it go out of scope
Truss.pause.hit_stop(0.08, 0.05)                                    # 80 ms at 5 % speed, then restore
Truss.pause.is_paused()
Truss.pause.holders()                                               # [&"inventory_menu"], for the debugger tab
```

- `get_tree().paused` is true while at least one token is held. Releasing a token never unpauses a game that
  another token still holds. Tokens release themselves when freed.
- Hit stop uses `Engine.time_scale` with a timer that ignores the time scale, and stacks: overlapping hit stops keep
  the lowest scale until the last one ends. It doesn't touch `paused`.
- App lifecycle: the `Truss` autoload publishes `TrAppEvents.FocusLost`, `FocusGained`, `Paused`, `Resumed` and
  `QuitRequested` on the container's `TrEventBus` (if registered). Setting `truss/lifecycle/pause_on_focus_loss`
  (default `false`) acquires a token automatically on focus loss.
- The debugger tab shows current pause holders.

## 7. D — TrEventBus: priority and source

```gdscript
bus.subscribe(EnemyDied, _on_enemy_died)                          # unchanged
bus.subscribe(EnemyDied, _count_score, {priority = 10})          # higher runs first; ties keep subscription order
bus.subscribe(Damaged, _on_my_damage, {source = self})            # only events published with this source
bus.publish(Damaged.new(5), self)                                 # source is optional
```

- Options are a `Dictionary` so the signature stays backward compatible. Unknown keys are reported.
- A handler without `source` receives every event of the type (broadcast), as today. A handler with `source`
  receives only events published with that same source. This replaces id filtering with `get_instance_id()`.
- `TrEvent` gets an optional `source` property, set by `publish(event, source)`, so handlers can tell who sent it.
- Lightweight events: the guide shows declaring many small events as inner classes of one named script
  (`class_name GameEvents` with `class StaminaChanged extends TrEvent:`), readable thanks to F.

## 8. E — State machine arguments and intents

```gdscript
machine.transition_to(EnemyHurt, {hitstun = 0.3, knockback = Vector2(120, 0)})

# in EnemyHurt
func enter(_previous: TrState) -> void:
	var stun: float = machine.transition_args.get(&"hitstun", 0.2)

# player input and AI both send intents
machine.send_intent(&"attack")
func handle_intent(intent: StringName, _data: Dictionary) -> bool:   # leaf first, bubbles to parents
	if intent == &"attack":
		machine.transition_to(PlayerAttack)
		return true
	return false
```

- `transition_args` is valid during `enter` of the new states and stays readable until the next transition.
  `enter(previous)` keeps its signature: no breaking change.
- `send_intent(intent, data = {})` returns whether a state handled it. It's the AI-and-player-friendly counterpart
  of `handle_input`, and the debugger can log intents.

## 9. F, G — Names, Truss Lite, stateful Resources

- **F**: `TrContracts.describe()` resolves inner classes of named scripts to `Outer.Inner` through the global class
  list, cached after the first lookup. `module_name()` overrides keep working.
- **G1, Truss Lite**: a guide with three entry levels, each a complete example:
  1. *Arcade*: `TrEventBus` in one autoload + `TrResult`; optionally a `TrStateMachine` for the game phase.
  2. *Mid-size*: plus `TrRegistry`, `TrStats`, `TrPause`, without modules or DI.
  3. *Full*: modules, DI, mediator, `arch_check`.
- **G2, arch_check rule** `stateful_resources` (off by default): reports `var` declarations that are neither
  `@export` nor `@export_storage` in scripts extending `Resource`, in the configured **layers** (for example
  `["domain"]`; layers instead of folders, to match the other rules). That's where the shared runtime-state bug
  comes from.

## 10. Out of scope

| Idea | Why not in 0.5 |
|---|---|
| Idle-economy module (wallet, cost curves, number formatting, tick loop, offline progress) | Evidence from one project only. Planned as an optional add-on (`addons/truss_idle`) for 0.6, reusing `TrStat` and `TrResult` |
| Save system | None of the reviewed projects has one beyond a raw high-score file. Needs its own RFC |
| Dialogue, quests, object pools, audio voice pool | No evidence, or too game-specific. The audio pool becomes an `examples/` recipe |

## 11. Compatibility

No breaking changes: every API above is new or adds optional parameters. `TrEventBus.subscribe()` keeps its
two-argument form, `TrState.enter()` keeps its signature, and the debugger messages gain fields without
renaming existing ones.

## 13. Open questions

| # | Question | Proposal |
|---|---|---|
| Q1 | Stat formula order | `(base + flat) × (1 + Σ percent) × Π multiply`, the most common in RPG/roguelite games |
| Q2 | Event source matching | Exact object identity; handlers without a source receive everything |
| Q3 | Should `pause_on_focus_loss` default to `true` on mobile? | Default `false` everywhere, documented as recommended on mobile |
| Q4 | Hit stop: `time_scale` or `paused` | `time_scale` (keeps UI and particles alive); verify timer accuracy first |
| Q5 | Registry keys | `id` property if the script has one, else the basename; configurable with `id_property` |
